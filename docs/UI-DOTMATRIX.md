# 点阵设计语言（Dot Lattice）

> 目的：让点阵从「会呼吸的壁纸」变成**布局与交互的骨架**。
> 参考：Material 3 Expressive for Wear OS（2025-08）、SAP Fiori for Wear OS layout foundation。
> 本文是判据，不是灵感清单——每条都可被代码和截图检验。

## 一、要解决的问题

设置页重做前的问题清单（真机截图逐条确认过）：

1. **每行一张圆角卡**——四五张叠成"一摞药丸"，组内呼吸与组间呼吸看起来一样，分组读不出来。
2. **右侧取值贴死圆角**——padding 只给了 start/top/bottom，漏了 end。
3. **滑轨是一条 14dp 实心高饱和蓝胶囊**——强调色铺开成大面积，违反「重音不是装饰」。
4. **全页无唯一焦点**——每行等权，眯眼看是一整片均匀灰块。

更深一层的原因：**背景点阵与前景元素是两套互不相干的坐标系**。背景自己呼吸，前景自己堆卡片，两者没有任何几何关系，所以无论怎么调卡片圆角，都像"随便拼的"。

## 二、网格规范

| 项 | 值 | 来源 |
|---|---|---|
| 格距 | 16dp（可由 `matrixSpacingDp` 调到 0–64） | `UnifiedMatrixCanvas(gridSpacingDp=16f)` |
| 锚点 | 画布几何中心 | `buildMatrixGrid`：`centerX = width/2` |
| 裁剪 | 圆形盘，只保留 `distCenter <= min(w,h)/2` 的点 | 同上 |
| 主键原点 | 屏宽/2，屏高 − 34dp | `micOriginY = boxHeightPx - 34.dp` |
| 内容安全宽 | 184dp（176dp 内容盒 + 左右 14dp 内边距） | `SettingsDesignMath.ContentWidthDp` |

**网格是唯一的度量单位。** 任何新的间距/尺寸都必须能写成格距的简单分数或倍数（¼ / ½ / 1 / 1.5 / 2），
不能出现"看起来差不多"的随手值（12dp、14dp 这类必须能解释成 16×¾ / 16×⅞）。

## 三、三条法则

### 法则 1 · 元素落在格点上
交互元素的**中心**必须落在格点（或格点的半格偏移）上。允许偏差 ≤ 1dp。
- 主键：已经在画布中心（合法）。
- 左右翼按钮：落在相对中心 ±2 格（±32dp）处。
- 设置页的行首标记：落在左槽线所在的格列上。

### 法则 2 · 交互 = 格点形变，不是元素浮起
按下任何交互元素时，**格子本身**要形变，而不只是元素自己缩放：
- 被按的格点放大（scale ≥ 1）；
- 周围格点沿**径向被推开**，推开量随距离平滑衰减到 0；
- 用弹性曲线回到原位（`spring(0.62f, 420f)` 或 `Wear.Motion.micro()`）。
- 幅度为 0 时必须与改造前逐像素相同，并走原有快路径。

### 法则 3 · 留白由格距推导，不用分隔线堆装饰
- 组内行距 = 0（同卡相接），组间 = 24dp = 1.5 格。
- 组内只用一种线：1 物理像素 Border 发丝线，右端从槽线左收 24dp。不再排点线。
- 组标题左槽沟里画 8dp × 2dp 的运行时强调色短横；14dp 左槽线与 8dp 短横之间保留 6dp，避免读成连字符。
- 禁止再出现"每行一张独立卡片"。

### 法则 4 · 一页一个主气球，宽度只跟屏幕圆弦
- 设置根页与每个子页都只保留**一个主气球**；分区标题、卡片行与卡外动作块全部装进同一条闭合轮廓，不再拆成多个小气球各自为政。
- 外壳宽度取所在高度的屏幕弦长，中心最多 216dp，向屏幕上下边缘连续收缩；每一行共享同一弦宽，整页由一条 Catmull-Rom 转三次贝塞尔的轮廓封合。
- 组首 / 组尾只用 20dp 单段浅弧收口，端点和侧边共用切线；没有第二个圆拱。
- 内容只允许**等比缩小**：屏心 1.0×，靠近屏幕边缘才收小；严禁 `scaleX` 单独拉伸、严禁任何横向形变动画。
- `ScalingLazyColumn` 只负责滚动与视口裁剪，`edgeScale = 1`、`edgeAlpha = 1`；官方滚动显隐交给 `ScreenScaffold.edgeButton`，不逐行缩放。

## 四、各界面映射

### 聊天页
- 背景点阵：常驻（滚动期间不冻结——实测冻结只省 3.5 个百分点，观感更差）。
- 主键按下 → 点阵被顶开（法则 2 的正式落点）。
- Agent 回复：Surface → SurfaceAlt 纵向渐变，无常态描边；只有审批态才出现 1dp 边界。
- 用户消息：AccentSurface → 强调色渐变，右下角收小尾，其余角保持大圆角；不做四角同半径的旧式气泡。

### 设置页
- 每页一个主气球：中心 216dp、边缘按圆弦连续收缩、20dp 浅弧收口；内容基准 176dp。
- 行内左右各 14dp；内容只在屏幕边缘等比缩小，屏心保持原始字号。
- 返回键使用官方 `ScreenScaffold` + `EdgeButton`：滚到列表末尾放大淡入，向上滚缩小淡出；不再保留左上角圆形返回键与底部重复“完成返回”。
- 强调色只允许出现在组标题短横、滑轨已选段、单选选中态；语义色只允许出现在 6dp 状态点上，且一页最多一处。
- 标题与取值共享 148dp 行内宽；按 15sp 保守估宽放不下时，取值整段移到标题下方，标题不得为取值让位而折行。
- 子页标题已承担分组语义时，不再重复渲染同名的首个组标题。
- 页顶唯一焦点：当前模型名（18sp Medium）+ baseUrl（12sp Muted）。

### 引导页
- 五页共用 96dp Canvas、40dp 外环与四个方位点；图形保持静态，动效只做 4dp 入场位移。
- 标题是主焦点，说明使用次级文本色；审批示意保持单色强调面，不用大面积红绿表达放行/拒绝。
- 页脚只留「跳过 / 继续」两类元素左右分置；页码点在说明文字正下方，与页脚保留独立 8dp 间隔。

## 五、禁忌（出现即判不合格）

1. 每行一张独立圆角卡。
2. 强调色铺成大面积实心块（如 14dp 实心滑轨）。
3. 三类元素并排在同一条基线上（跳过 + 页码点 + 按钮）。
4. 文字贴到卡片圆角上（右端无内边距）。
5. 一屏出现两个等权焦点。
6. 用字号堆层级而不改字重。
7. 新增颜色 token（主题固定 14 个，`PaletteAuditTest` 会验收）。

## 六、已落地的实现（避免文档与代码脱节）

| 法则 | 落点 | 关键常量 |
|---|---|---|
| 法则 1 格点对齐 | `DotLattice` 纯对象 | 格距 16dp、锚点=画布中心 |
| 法则 2 交互=格点形变 | `UnifiedMatrixCanvas(keyPressAmplitude)` | falloff 3.5 格=56dp、峰值位移 0.9 格、半径增益上限 35% |
| 法则 3 发丝分隔 | `SettingsGroupLineMath` | 1 物理像素 Border、右端留 24dp |
| 组标题签名 | `SettingsSectionHeaderMark` | 8dp × 2dp 强调色短横、14dp 左槽线、6dp 间隔 |
| 一页一个主气球 | `SettingsCurveGeometry.groupPath` | 全页共享一条屏幕弦长轮廓、20dp 单段浅弧收口 |
| 内容只缩不放 | `SettingsCurveMath.halfWidthDp` | 屏心 1.0×，靠近屏幕边缘等比缩小；禁止横向拉伸 |
| 官方滚动返回键 | `ScreenScaffold.edgeButton` + `EdgeButton` | `edgeScale = 1f`、`edgeAlpha = 1f`；按钮随列表末尾放大/淡入 |
| 唯一焦点 | 设置根页焦点块 | 模型名 18sp Medium + baseUrl 12sp Muted |
| 语义色只染点 | `SettingsStatusDot` | 6dp 状态点，一页最多一处 |

真机实测佐证（233dp 表，2px/dp）：
- 点阵按下形变：60–120px 环带变化 1564 个像素，120px（60dp）以外 **0** 像素变化 → 径向梯度而非整盘平移。
- 空闲静止：间隔 200ms 两帧差分 **0** 像素 → 空闲相位量化仍在生效，绘制指令被整帧复用。
- 1.0 帧耗时：p50 18ms（仅超 16.7ms 预算 1.3ms），CPU p90 22ms，GPU p90 9ms。

### 圆屏顶部弦长约束（容易被忽略）

固定头从 y=0 起算。233dp 圆（r=116.5）的弦长随 y 增长：

| y | 弦长 |
|---|---|
| 5dp | 68dp |
| 13dp | 107dp |
| 24dp | 143dp |

所以**贴在圆屏最顶部的标题，可用宽度只有约 107dp**（18sp 下约 12 个拉丁字符或 5 个汉字）。
审批浮层三个标题因此受限：中文「高风险操作 / 需要确认 / 低风险」都在 90dp 以内；
英文原先 `High-risk action`（≈140dp）与 `Needs confirmation`（≈155dp）会被圆周切掉边缘，已缩短为 `High risk`（≈81dp）与 `Confirm`（≈63dp）。
新增顶部长文案时先按这张表核宽度，不要靠加顶部留白解决——留白是从内容带里扣的。

## 七、可检验指标

| 指标 | 上限 | 检验方式 |
|---|---|---|
| 每页强调色元素数 | ≤ 3（设置根页 0） | grep `Wear.Accent` |
| 每页分隔线根数 | = 子项组数 | grep `SettingsGroupHairline` 调用点 |
| 组间/组内间距比 | ≥ 2 | `SettingsDesignMath.sectionToRowRatio` |
| 每页字号种类 | ≤ 3 | grep `.sp` |
| 格点对齐偏差 | ≤ 1dp | 单测 `DotLatticeTest` + 截图量 |
| 按下时中心 3 环位移 | 单调递减到 0 | 单测 |
