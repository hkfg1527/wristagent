# 点阵设计语言（Dot Lattice）

> 目的：让点阵从「会呼吸的壁纸」变成**布局与交互的骨架**。
> 参考：Material 3 Expressive for Wear OS（2025-08）、SAP Fiori for Wear OS layout foundation。
> 本文是判据，不是灵感清单——每条都可被代码和截图检验。

## 一、要解决的问题

设置页重做前的问题清单（真机截图逐条确认过）：

1. **每行一张圆角卡**——四五张叠成"一摞药丸"，组内呼吸与组间呼吸看起来一样，分组读不出来。
2. **右侧取值贴死圆角**——padding 只给了 start/top/bottom，漏了 end。
3. **滑轨是一条 14dp 实心高饱和蓝胶囊**——强调色铺开成大面积，违反「重音不是装饰」。
4. **全页无唯一焦点**——每行等权，眯眼看是一整片均匀灰块。

更深一层的原因：**背景点阵与前景元素是两套互不相干的坐标系**。背景自己呼吸，前景自己堆卡片，两者没有任何几何关系，所以无论怎么调卡片圆角，都像"随便拼的"。

## 二、网格规范

| 项 | 值 | 来源 |
|---|---|---|
| 格距 | 16dp（可由 `matrixSpacingDp` 调到 0–64） | `UnifiedMatrixCanvas(gridSpacingDp=16f)` |
| 锚点 | 画布几何中心 | `buildMatrixGrid`：`centerX = width/2` |
| 裁剪 | 圆形盘，只保留 `distCenter <= min(w,h)/2` 的点 | 同上 |
| 主键原点 | 屏宽/2，屏高 − 34dp | `micOriginY = boxHeightPx - 34.dp` |
| 内容安全宽 | 184dp（176dp 内容盒 + 左右 14dp 内边距） | `SettingsDesignMath.ContentWidthDp` |

**网格是唯一的度量单位。** 任何新的间距/尺寸都必须能写成格距的简单分数或倍数（¼ / ½ / 1 / 1.5 / 2），
不能出现"看起来差不多"的随手值（12dp、14dp 这类必须能解释成 16×¾ / 16×⅞）。

## 三、三条法则

### 法则 1 · 元素落在格点上
交互元素的**中心**必须落在格点（或格点的半格偏移）上。允许偏差 ≤ 1dp。
- 主键：已经在画布中心（合法）。
- 左右翼按钮：落在相对中心 ±2 格（±32dp）处。
- 设置页的行首标记：落在左槽线所在的格列上。

### 法则 2 · 交互 = 格点形变，不是元素浮起
按下任何交互元素时，**格子本身**要形变，而不只是元素自己缩放：
- 被按的格点放大（scale ≥ 1）；
- 周围格点沿**径向被推开**，推开量随距离平滑衰减到 0；
- 用弹性曲线回到原位（`spring(0.62f, 420f)` 或 `Wear.Motion.micro()`）。
- 幅度为 0 时必须与改造前逐像素相同，并走原有快路径。

### 法则 3 · 留白由格距推导，不用分隔线堆装饰
- 组内行距 = 0（同卡相接），组间 = 24dp = 1.5 格。
- 分隔只用两种：**发丝线**（1px，Border 色，从右槽线左收 24dp）或**点线**（沿格距排列的小点）。
- 禁止再出现"每行一张独立卡片"。

## 四、各界面映射

### 聊天页
- 背景点阵：常驻（滚动期间不冻结——实测冻结只省 3.5 个百分点，观感更差）。
- 主键按下 → 点阵被顶开（法则 2 的正式落点）。
- 消息卡：单一 Surface + 1dp Border，全宽，不做嵌套卡片。

### 设置页
- 组 = 一张卡（组首上圆角 / 中间方角 / 组尾下圆角，16dp）。
- 行内左右各 14dp；取值右端距卡缘 14dp。
- 强调色只允许出现在**两处**：滑轨已选段、单选选中态。
- 语义色只允许出现在 6dp 状态点上，且一页最多一处。
- 页顶唯一焦点：当前模型名（18sp Medium）+ baseUrl（12sp Muted）。

### 引导页
- 示意图用 Canvas 手绘，元素落在同一格距上。
- 页脚只留「跳过 / 继续」两类元素左右分置；页码点在说明文字正下方。

## 五、禁忌（出现即判不合格）

1. 每行一张独立圆角卡。
2. 强调色铺成大面积实心块（如 14dp 实心滑轨）。
3. 三类元素并排在同一条基线上（跳过 + 页码点 + 按钮）。
4. 文字贴到卡片圆角上（右端无内边距）。
5. 一屏出现两个等权焦点。
6. 用字号堆层级而不改字重。
7. 新增颜色 token（主题固定 15 个，`PaletteAuditTest` 会验收）。

## 六、可检验指标

| 指标 | 上限 | 检验方式 |
|---|---|---|
| 每页强调色元素数 | ≤ 3（设置根页 0） | grep `Wear.Accent` |
| 每页分隔线根数 | = 子项组数 | grep `SettingsGroupHairline` 调用点 |
| 组间/组内间距比 | ≥ 2 | `SettingsDesignMath.sectionToRowRatio` |
| 每页字号种类 | ≤ 3 | grep `.sp` |
| 格点对齐偏差 | ≤ 1dp | 单测 `DotLatticeTest` + 截图量 |
| 按下时中心 3 环位移 | 单调递减到 0 | 单测 |
