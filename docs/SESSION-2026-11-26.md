## 6. 这次踩过、别再踩的坑

| 坑 | 事实 |
|---|---|
| 猜无障碍属性名 | `selectable` 投影成 **`checkable`/`checked`**，不是 `selected`；先 dump 再写判据 |
| `crown()` 表冠注入 | 注进 `/dev/input/event0`（电源键），**到不了应用**；滚动一律用 `input swipe`，每步 150px + dump |
| 视觉对比图 | 两张图必须**同一滚动位置、同一缩放状态**，否则比的是两件事（D6 曾因此误判） |
| 方形截图判布局 | 必须圆屏裁图后再看（用户提过两次） |
| CRLF | 用 `Replace` 改 Windows 上的源文件常常**静默不匹配**；改完必须 `git status` / grep 复核 |
| 改文档不会触发单测 | 读文件的守卫（版本行等）要 `--rerun-tasks` 才真跑 |
| `release-check --skip-*` | 退出码 **2 = 不完整**，不能当门禁通过；跳过项现在会列名 |
