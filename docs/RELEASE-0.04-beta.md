# 0.04-beta · 设置页四套风格

## 四套页面风格，随时切换
外观与点阵 → 页面风格，四档实时生效：

- **气泡**：整页一个气球，宽度沿屏幕圆弦收缩（默认，老用户升级后像素不变）。
- **方角**：不画曲面，文字居中、横线分隔，返回键是 40dp 方框描边键。
- **谷歌大卡片**：一行一张独立圆角卡，根页三张 hero 卡（模型 / 工具与 MCP / 语音）。
  颜色、圆角、环直径按 Pixel Watch 2 上 Google Health 的实测像素定：卡片底 `#2A313C`、
  强调色 `#7FCFFF / #A8C7FA / #C4EED0`、环轨道 `#48556A`、环直径 50dp、圆角 24dp。
- **终端**（原创）：整页等宽字体、没有底色与圆角，组标题带箭头前缀。

风格真值落在偏好仓库，配置导入导出与网页控制台共用同一份。

## 气球轮廓重做
上一版肩部靠闭合 Catmull-Rom 平滑，切线被邻居拉偏，在圆弦外鼓出 8dp（实机 461px 对侧壁 431px）。
现在侧壁取圆弦的解析导数、收口是同一个窗口函数，整圈一条连续曲线；穹顶高度按半宽反解（20dp 起、
最高 48dp），不会再压成「平盖 + 中间一个尖」。几何约束由 `SettingsBalloonOutlineTest` 钉住。

## 五项新的 Agent 设置
请求超时（10–180s）、自动重试（0–3 次）、重试退避（0–5000ms）、仅 WiFi 请求、触觉反馈。
五项都有真实消费点（调度器的读超时与重试循环、连接前的网络闸门、震动入口），
也都能从网页控制台改。

## 网页控制台
新增「网络与反馈」页；修掉一个真实缺口：`SERVER_KEYS` 少了 7 个已可写的键（含此前的回答风格），
网页端提交时会被本地剔除，手表永远收不到。

## 工具调用账本
工具卡现在用圆环显示「已调用 / 已注册」，没有数据时显示 `—`。

## 实测
- 单测 **1167 例全绿**。
- 设备：TicWatch Pro 5（466×466 / 233dp）。
