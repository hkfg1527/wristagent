# Wrist Agent 0.03-beta

首个公开测试版。面向 Wear OS 圆屏手表，目标是让 AI Agent、设置与动效都遵循同一套圆形空间语言。

## 下载

- APK：`wear-0.03-beta.apk`（GitHub Release 资源）
- 包名：`dev.ghr.wristagent`
- 最低系统：Android 13 / Wear OS（minSdk 33）

## 重点

### 圆屏视觉
- 设置根页与每个子页只保留一个主气球：所有分区、卡片行与动作块共享同一条屏幕弦长轮廓。
- 卡片外壳沿屏幕圆周收缩，顶底只用 20dp 单段浅弧收口；不再使用矩形整体缩放或第二段圆拱。
- 文字只做等比缩小，屏心保持 1.0×；彻底取消横向拉伸和字宽变形。

### 官方 M3E 返回键
- 子页改用 `ScreenScaffold` + `EdgeButton`：滚到列表末尾放大淡入，向上滚缩小淡出。
- 开关收成右槽 44×26dp 胶囊，不再用全宽蓝色大胶囊；带本地化的开/关无障碍状态，主气球顶部加静态受光渐变。
- 返回键与列表共享滚动手势，不再是固定浮层。
- 移除左上角圆形返回键和重复的“完成返回”。

### 对话
- Agent 回复使用 Surface → SurfaceAlt 渐变，无常态描边；审批态才出现边界。
- 用户消息使用强调色渐变与不对称小尾。
- 消息入场只从 1.02 等比收回，不做横向形变动画。

### 设置与 Agent
- 新增回答风格三档（精炼 / 平衡 / 详尽），写入系统提示词，纳入配置导出和网页控制台字段。
- MCP 客户端、长期记忆写入、手势绑定、工具审批、沙箱等级、配置导入导出均保留。
- 设置页补齐回答风格、字号、强调色、模型参数、语音、工具、安全、关于等页面。

## 已知限制
- 圆屏曲面按屏幕弦长计算，192dp 窄屏的外壳余量小于 233dp 屏。
- 内容在房间边缘等比缩小时可能小于常规字号；这是为了不横向拉伸字形的取舍。
- 旧式 MCP 分离式 SSE 传输未实现。
- 网络体检页未在本轮重新截图。

## 校验
- 单元测试：以 `.gradlew.bat :wear:testDebugUnitTest --offline` 为准。
- 构建：`.gradlew.bat :wear:assembleRelease --offline`。
