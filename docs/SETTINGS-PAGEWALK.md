# 设置页巡检表（判据：能打开 + 能返回根页 + 页内至少有 3 条文本）

巡检脚本：`build-logs/pagewalk.ps1`（ASCII，标题读 `pagewalk-targets.json`，UTF-8 显式读取）。
判据三条同时成立才记 ok：

1. 点进去后 dump 里出现该页标题；
2. 按返回键后回到**根页**——判据是 dump 里出现任一"只在根页出现"的标签
   （四个分区标题 / 完成返回 / 网页控制台 / 标准提示 / 全部启用）；
   只看分区标题会误判：根页会记住滚动位置，返回时往往停在中段，分区标题不在屏内；
3. 页内文本节点 ≥ 2（防"标题在了但内容空白"；关于页本身只有两行，阈值不能定 3）。

脚本细节（都是踩过的坑）：
- 表冠方向：本机 `+5` 是往上（回顶），`-5` 是往下。搞反会让"滚到顶"实际滚到底。
- 返回后要轮询最多 4 次（转场动画没结束时 dump 到的还是上一页）。
