# 设置页风格重做计划（UI 第一优先）

> 用户 2026-11-18 定：**UI 第一优先，核心功能往后放；风格不许大杂烩，每套要能单独讲清楚**。
> 目标形态：4 套现有 + 1 套新增 = **5 套风格，每套内部自洽**；
> 其中 M3E 那套全程只用官方组件，不掺手搓件。

## 1. 现状（2026-11-18 实测）

| 事实 | 值 |
|---|---|
| 风格枚举 | `BALLOON` / `SQUARE` / `GOOGLE_CARD` / `TERMINAL`，**4 套**（文档写"5 种"是错的） |
| 风格判断点 | `WearAppearance.style ==` **10 处**、`style ==` 比较共 **12 处** |
| 分布 | `SettingsShared.kt` 7、`SettingsScreen.kt` 2、`SettingsRowText.kt` 1、`SettingsRowStagger.kt` 1、`SettingsCardEdgeZoom.kt` 1 |
| 混用现状 | 同一套风格里既有官方 `Card`/`ScreenScaffold`，也有手搓 `SettingsCompactSwitch` / `SettingsThinSlider` / 圆点 / 返回控件 |

**结论**：现在不是"四套风格"，是"一份实现 + 十处 if"。用户看到的"一会儿 M3E 一会儿基础"，就是这些 if 各走各的。

## 2. 目标契约（每套风格必须自己回答这 8 个槽位）

| # | 槽位 | 谁能决定 | 不允许 |
|---|---|---|---|
| 1 | 页面骨架（是否 `ScreenScaffold` / 时钟 / 滚动指示器） | 风格 | 一个风格里两种骨架混用 |
| 2 | 组标题（有无、样式、前缀） | 风格 | 同一风格里两种组标题 |
| 3 | 行外壳（卡片 / 发丝线 / 无壳） | 风格 | 行外壳由 `if` 临时决定 |
| 4 | 开关控件 | 风格 | M3E 档里出现手搓开关 |
| 5 | 滑杆控件 | 风格 | M3E 档里出现自绘轨道 |
| 6 | 单选控件 | 风格 | 一半圆点一半官方 |
| 7 | 返回控件（列表行 / EdgeButton / 顶栏） | 风格 | 同一风格返回位置随页面变 |
| 8 | 排版（字号三档、字体族、行高） | 风格 | 页面自己改字号 |

实现方式：`SettingsStylePolicy` 一张表声明 8 个槽位，**渲染代码只读表，不许再写 `if (style == ...)`**。
`SettingsStylePolicyGuardTest` 钉住：每套风格 8 个槽位都必须有值、且值互不矛盾。

## 3. 五套风格的定义（第 5 套待命名）

| # | 风格 | 一句话定位 | 组件来源 | 状态 |
|---|---|---|---|---|
| 1 | 气泡 BALLOON | 整页一块连续曲面，行贴着屏幕圆弦走 | 手搓曲面 + 官方 Card（组） | 需收口 |
| 2 | 方角 SQUARE | 全直角、横线分隔、文字居中 | 无壳 + 发丝线 | 需收口 |
| 3 | 大卡片 GOOGLE_CARD | **100% 官方 Wear M3**：ScreenScaffold + TimeText + ScrollIndicator + Card + 官方控件 | 官方 | 本轮起作为基准档重做 |
| 4 | 终端 TERMINAL | 等宽、无壳、`> ` 前缀，抄端点用的极简档 | 无壳 + 等宽 | 需收口 |
| 5 | 待定 | 建议：**M3 列表档**（官方 `TransformingLazyColumn` + 官方 `SwitchButton`/`Slider`/`RadioButton` 整行胶囊） | 官方 | 新增 |

第 5 套的理由：大卡片档是"一行一张卡"，而官方 M3 还有另一种常态——**一行一个胶囊控件**。
两者都用官方件，但密度完全不同，用户在表上会想要两种。

## 4. 迁移顺序（每轮一小步，每步真机截图）

1. **建表**：`SettingsStylePolicy` + 守卫测试（本轮）。
2. **M3E 档基准**：GOOGLE_CARD 全链路只用官方件（开关 / 滑杆 / 单选 / 返回 / 骨架），其余档不受影响。
3. **把 if 搬进表**：10 处判断点逐个改成读表，每改一处跑一次单测 + 真机。
4. **新增第 5 套**：官方胶囊列表档，复用第 2 步的官方件。
5. **收口其余三套**：各自把"手搓 vs 官方"统一成一套说法，写进本文的"每套风格说明书"。

## 5. 验收口径（每套风格都要过）

- 同一风格内**槽位一致**：抽查任意两个页面，返回控件位置、组标题样式、行外壳三件事必须同源。
- **不许混用**：M3E 档的 `SwitchButton`/`Slider`/`RadioButton` 必须是官方 import，守卫测试扫描源码断言。
- 每套风格一张真机截图 + 一张"槽位表"，放进 `docs/device/v11/style-<name>-*`。
