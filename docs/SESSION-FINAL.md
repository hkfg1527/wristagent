## 二、已真机闭环的行为（TERMINAL）

- 行网格 36px / 一屏 10 行（另有 CI 几何断言 `TerminalGridTest`，做过变异测试）
- `─`×30 规则线、`▓/░` ASCII 滚动条、`# ` 分区头、钉底状态条 `> █  n/4·NL  [ 风格 ]`
- 单按一行（`delta=36 repeat=0`）、长按一屏（`delta=360 repeat=1`，底栏分区 1/4 → 3/4）
- Enter 执行焦点行：两次 ENTER = 两条回显、粘性焦点、不崩溃、不退出页面
- 焦点行反白（像素带 35px、步进 36px）
- 字符菜单选择器；返回键只关菜单不关页面
- 无涟漪（`indication = null`）；滑动不误执行；装饰字符不进语义树
- 回显上限 3 行 + 跟随到底；回显行数计入底栏 `NL`
- 点状态段 → 打印 `# [ ON ] 开关 · /open`（帮助入口）
- 可操作行读屏语义：`标题，打开` / `标题，开|关`
- **字符菜单（`[ 风格 ]`）完整可用键盘**：表冠/音量键移光标（`>`），Enter 选中；关闭后按键归属自动还原
  （真机回归：菜单关闭后 14 次 VOLUME_UP 把分区从 4/4 带回 1/4）

## 五、踩过的坑（别再踩）

1. **崩溃日志不在你的 tag 里**：排查"点了没反应"先看 `adb logcat -d -t 300 | grep FATAL`。
   本会话有一次"ENTER 时好时坏"其实是 `LazyColumn` 的重复 key 崩溃。
2. **dump 里文本完整不等于屏幕上完整**：banner 和帮助行都被裁切过，只有截图能发现。
   终端里所有固定宽度文本都要有**长度守卫**。
3. **页面身份标记必须与滚动位置无关**（用 `[ 风格 ]` / `[n/4]`），不要用顶部标题。
4. **`>` 在 dump 里是 `&gt;`**。
5. **Robolectric 断言某行前必须保证它在视口内**，否则"查不到"会被误读成"没实现"。
6. **合并语义**：`clickable(enabled = false)` 仍会合并子树，查子节点要 `useUnmergedTree = true`。
7. **PowerShell 不要做 Kotlin/String 结构改写**：本会话三次翻车（删块把源文件删坏、
   插入 import 粘成 `TerminalTrackCellimport`、`\n` 字面量把下一行注释掉）。
   替换后必须校验"目标行数"，不能只看编译是否通过。
8. **`[System.IO.File]::WriteAllText` 用进程 CWD**，不是 PowerShell 的 `cd` —— 用绝对路径。
9. **测量工具本身要复位**：`style-shots` 截图前要 BACK 再进页，否则残留回显会污染哈希。
10. **网格/基准与被测值必须来自不同来源**，否则断言永远绿（变异测试才发现过一次）。
11. **页面上可能有两处同名文案**：`页面风格` 既是菜单头也是终端行标题，用它判断"菜单是否关闭"会永远为真；
    要用菜单专有的 `esc 取消`。
12. **测方向性功能先确认当前值不在边界**：在列表最后一项按"往下"当然不动，一次差点误判成 bug。
