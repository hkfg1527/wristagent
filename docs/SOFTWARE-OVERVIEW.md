# Wrist Agent · 软件现状说明（2026-11-10）

## 这是什么

一只戴在手腕上的 AI Agent。不是“手表版聊天框”，而是能在设备上**真的做事**的代理：
它可以读电量、看天气、调点阵、开省电、发振动，也能调用自己造的工具去执行 shell 命令（受审批与安全策略约束）。

- 包名 `dev.ghr.wristagent`，versionName `0.01`，minSdk 33，targetSdk 37
- 单模块 `:wear`（另一个 `mobile` 模块是模板死代码，待删）
- 体积：release APK 3.4 MB（R8 已开）

## 界面结构（四个屏）

| 屏 | 内容 |
|---|---|
| 聊天 | 弧形时钟 + 答案面 + 底部主键；点阵背景只在活动状态增强 |
| 设置 | 中心轴排版，9 个分组页，57 个字段 |
| 审批 | 全屏接管，滑块左滑放行 / 点击拒绝，风险分三档 |
| 引导 | 粒子开场 → 白圆欢迎 → 配置表单 |

## 三条能力主线

1. **对话与工具调用**：模型 → 工具调用 → 审批 → 执行 → 回填，全链路在设备上完成
2. **设备控制**：电量/温控/振动/点阵/省电/天气，走 `SelfDefinedTools` 与 `AgentToolRegistry`
3. **双端控制**：手机浏览器访问手表上的网页控制台，改那 18 个手表端不可写的字段

| 项 | 现状 |

## 已知短板（按优先级）

1. **高度可自定义不足**：18 个字段手表端只读，必须去网页改；自定义提示词/角色卡也只有网页能改
2. **两个假开关**：边说边显示、记住此命令——能拨但没有任何效果
3. **滚动性能**：janky 66–70%，瓶颈在 UI 线程组合与测量
4. **引导页缺手势教学**：新用户不知道长按说话、上滑进设置
5. **已删除（输入方式改由左翼直接打开输入框决定）**：输入方式二选一状态；同批完成引导重写与网页端补齐，1.0 收口未开始

## 环境与工具

- 构建必须 `--offline`（本机有 TLS 中间人）；`GRADLE_USER_HOME=D:\gradle-home`
- 本机 PowerShell 是 5.1，读写 UTF-8 源码要用 `[System.IO.File]` API
- 探针脚本：`docs/keycheck.sh`（密钥是否被掩码污染）、`docs/netcheck.sh`（手表网络出口）
