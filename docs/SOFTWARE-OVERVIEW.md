# Wrist Agent · 软件现状

> 快照于 2026-11-11（1.0）。**变更以 [CHANGELOG.md](../CHANGELOG.md) 为准，欠账以 [ISSUES.md](ISSUES.md) 为准，
> 设计规范见 [UI-DOTMATRIX.md](UI-DOTMATRIX.md)** —— 这份文件只说明"现在是什么样"。

## 这是什么

一只戴在手腕上的 AI Agent。不是"手表版聊天框"，而是能在设备上**真的做事**的代理：
读电量、看天气、调点阵、开省电、发振动，也能调用自己造的工具执行 shell 命令（受审批与安全策略约束）。

- 包名 `dev.ghr.wristagent`，versionName `1.0`，minSdk 33，targetSdk 37
- 单模块 `:wear`（另一个 `mobile` 模块已删除）
- 体积：release APK 约 3.6 MB（R8 已开）

## 四个屏

| 屏 | 内容 |
|---|---|
| 聊天 | 弧形时钟 + 答案面 + 底部主键。背景点阵随交互形变；有用户消息时回答靠左对齐，整屏只剩回答时居中 |
| 设置 | 9 个分组页。**组 = 一张卡**（组首上圆角 / 中间方角 / 组尾下圆角），组内用 16dp 格距的点线分隔；行内左右各 14dp；页顶唯一焦点是当前模型名 |
| 审批 | 固定头（标题 + 风险指示）+ 可滚动风险说明 + 滑轨。单击拒绝 / 左滑 85% 放行 / 长按 500ms 记住并放行 |
| 引导 | 5 页真实手势教学：长按 0.34s 说话、单击起录、上滑 38dp 进设置、横滑 22dp 弹两翼、滑轨放行 |

## 三条能力主线

1. **对话与工具调用**：模型 → 工具调用 → 审批 → 执行 → 回填，全链路在设备上完成。
   工具轮数无上限，子代理有独立上下文与深度上限（执行侧硬拒，不只是清单里不告知）
2. **设备控制**：电量 / 温控 / 振动 / 点阵 / 省电 / 天气，走 `SelfDefinedTools` 与 `AgentToolRegistry`；
   长期记忆有显式写入工具 `remember_fact`（强制审批档）
3. **双端控制**：手机浏览器访问手表上的网页控制台。手表端可写 37 项设置，网页端覆盖 35 项并额外提供
   数值滑杆与批量编辑；控制台由前台服务承载，按 HOME 离开应用后仍可访问

## 已建立的技术基线

| 项 | 现状 |
|---|---|
| 测试 | **1000 余条单测全绿**，含调色板 / 字阶 / 对比度 / 圆屏几何 / 点阵形变的结构守卫 |
| 设计令牌 | 15 个色值（正文约 9.3:1、辅助约 5.8:1，均过 AA）、字阶 12/15/18/24/30sp（相邻 ≥20%）、圆角 12/16/24/999dp、动效五档 |
| 点阵 | 格距 16dp、圆心为锚点。按下主键时该格放大 1.35 倍、邻点径向顶开，**56dp 外逐像素不动**；空闲时绘制指令整帧复用（实测两帧差分 0 像素） |
| 会话持久化 | 扁平文本 + Base64，JVM 可测，不依赖 `org.json` |
| 网页控制台 | 密钥掩码写回防护、按来源分桶限流、有界请求队列、`GET /healthz`、端口漂移可见 |
| 安全 | 命令审批 + 风险分档 + 允许清单（可记住可撤销）+ 沙箱三档 + 工具审批三档 + MCP 只认 http(s) 且拒绝跨主机重定向 |

## 已知短板

1. **强调色覆盖不完整**：聊天页里还有 20 余处直接读 `Wear.Palette.Accent` 的元素不跟随换色（令牌必须是常量）
2. **`remember_fact` 的分派跳只有源码级守卫**：它必经 `org.json`，而单测里那是 AGP 的桩
3. **帧耗时 p50 18ms**，刚超 16.7ms 预算；GPU p90 仅 9ms，杠杆在每帧绘制指令数
4. **192dp 窄屏**上设置根页不显示取值（既有规则），端口状态只在子页可见
5. **MCP 只实现 Streamable-HTTP 形态**，旧式「GET 长连 SSE + POST message endpoint」未实现

## 开发环境注意

- 构建：`./gradlew :wear:testDebugUnitTest --offline`
- 如果本机有 TLS 中间人代理，Gradle 走网会失败，用 `--offline` 或为代理 CA 配置信任
- **Windows + PowerShell 5.1**：读写 UTF-8 源码要走 `[System.IO.File]::ReadAllText/WriteAllText`，
  `Get-Content / Set-Content` 会按 ANSI 解码把中文读坏
