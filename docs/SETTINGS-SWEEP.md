## 判据（照 HANDOFF 写的来）

每页两条，缺一不通过：

1. **能打开** —— 点中根页那一行之后，根页的分区标题消失、屏上换成该子页的内容；
2. **能返回根页** —— 按一次系统返回，回到设置根页（回顶后能看到四个意图分区标题）。

判据**刻意不看"内容对不对"**：行内容各页差异太大，钉内容等于把测试写成文案快照。
"打不开""回不去"这两件事一旦发生，用户第一时间就会发现，先钉这两条。

## 顺带查出来一个真问题：4 页的标题和行名不一致

`docs/SETTINGS-IA.md` §4 的规矩是「**页面标题 = 根页行标题**，进出不换词，避免"我点的是哪个"」。
实测有 4 页破了这条：

|---|---|---|
| 模型与服务 | 模型与端点 | 行名 2026-11-15 大改时改过，页标题没跟上 |
| 模型参数 | 推理参数 | 同上 |
| 语音与唤醒 | 语音输入 | 同上 |
| 底栏副键 | 手势与侧键 | 同上 |

**下一步怎么修**：字符串成对改（`values/` + `values-zh/`），并同步
`SettingsIaDocNamingGuardTest` 里钉住的 19 个页面名。这条留到 0.0.0.48。

## 脚本踩过的四个坑（都写进代码注释了）

1. **一格表冠 ≈ 1/8 行**：`crown(-5, 8)` 大约走一行。一开始按"每步 2 格"写，等于原地踏步，
   于是每页都超步数、"滚不到"。
2. **找不到 ≠ 在下面**：访问过后面几页之后列表停在下方，目标行其实在视野**上方**，
   一路往下滚永远看不到 —— 「Lux 终端」因此连红三版。现在每页先回顶再往下扫。
3. **别要求"连续两次坐标一致"再落指**：列表带边缘缩放动画时坐标一直在微动，
   这个门槛会让点击**永远不会发生**，整轮全红。正确做法是睡够、单次读坐标、**用结果验证**。
4. **"回到根页"不能只认分区标题**：从「关于」返回时列表停在底部，屏上只有
   「配置导入导出 / 关于 / 完成返回」，按标题判断会误判成没回去，于是再按一次返回
   把设置页关掉（截图是表盘）。现在改成：按一次返回 → 轮询等 → **回顶再判**。
