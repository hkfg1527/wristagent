## 这是什么

运行在圆形表盘上的端侧 AI Agent。

它不是"聊天机器人套壳"：模型可以执行 shell 命令、在运行时给自己定义新工具、在专家模式下派生受限子代理。所有特权操作都要经过用户逐次审批。

## 设备支持

**当前只支持 Wear OS 4 及以上（Android 13 / API 33+）的圆形表盘设备。**

| 系统 / 设备 | 状态 | 说明 |
|---|---|---|
| Wear OS 4+（API 33+），圆形屏 | ✅ 支持 | 已在 **TicWatch Pro 5**（233dp / API 33，Magisk root）实机验证 |
| Wear OS 3（API 30 / 31） | ❌ 不支持 | minSdk 为 33，安装即被系统拒绝 |
| 非 Wear OS 手表（OPPO ColorOS Watch、华为 HarmonyOS、小米手表等） | ❌ 不支持 | 缺少 `com.google.android.wearable` 系统共享库；整套 UI 依赖 Wear Compose 的圆屏 inset 与旋转输入，这些系统没有对应实现 |
| API 30 实验包 | ⚠️ 仅供取证 | 可安装，但**预期无法正常运行**，仅用于收集崩溃日志以评估移植成本 |
| 方形屏 / 非手表设备 | ❌ 不支持 | 布局按圆形表盘半径设计 |

> 为什么只支持一种系统：整套界面基于 `androidx.wear.compose.material3`（Wear M3E），它需要 Wear OS 的窗口 inset、旋转输入与缩放列表行为。这不是"多打一个库就能跨平台"的问题。

## 没有 API Key，请自备

**仓库里没有密钥，发布包里也没有。**

- 构建过程**不读取任何密钥文件**，APK 内不存在任何 API Key
- 首次启动后，在手表设置页或网页控制台填入「接口地址 / API Key / 模型名」
- 支持任意 OpenAI 兼容端点（DeepSeek、硅基流动、自建网关等）
- 密钥只存本机 SharedPreferences，已关闭云备份；网页控制台响应中的密钥一律掩码

正因为不带任何凭据，这个仓库才可以安全地公开分享。

## 功能

| 模块 | 说明 |
|---|---|
| **Agent 循环** | 自主规划 → 调工具 → 看结果 → 继续；轮数不设上限，靠能量提示与空转检测兜底 |
| **特权执行** | `run_shell` 按 ROOT / Shizuku / 本进程三档自动选择，不可用时降级 |
| **自写工具** | `define_tool` / `list_tools` / `remove_tool`，定义即持久化 |
| **子代理** | `run_subagent` 仅在专家模式且开关打开时出现，独立上下文、不可再派生 |
| **审批门控** | 14 条破坏性命令规则 + rm 目标分类；破坏性操作强制审批、不可记住 |
| **会话持久化** | 会话落盘，重启恢复上次对话，历史灌回模型上下文 |
| **语音输入** | 长按说话、松手即转写；取消立即释放麦克风 |
| **局域网控制台** | 手表内嵌 HTTP 服务，手机浏览器改全部设置；四位数验证码 + 失败限流 |
| **思考胶囊** | 推理过程折叠为 30dp 细标签，展开流式滚动，结束显示真实耗时 |

## 构建

需要 JDK 17 与 Android SDK 37。

```bash
./gradlew :wear:assembleRelease
adb install -r wear/build/outputs/apk/release/wear-release.apk
```

签名材料（`keystore.properties` / `release.keystore`）不入库；缺失时自动退化为 debug 签名，保证任何人克隆后都能构建。

## 网页控制台

设置 → 网页控制台，显示形如 `http://192.168.1.x:8080/?t=1234` 的地址。

手机连同一 Wi-Fi 打开即可。验证码连错 5 次锁定 60 秒。网页端可改的字段比手表端更全，手表端承载不了的项会标注「请在手机网页修改」。

## 安全边界（务必阅读）

- 本应用**可以执行任意 shell 命令**。审批页是尊重用户的机制，**不是安全沙箱**。
- 破坏性命令（`dd of=/dev/block`、`mkfs`、`fastboot`、`pm uninstall com.android*` 等）每次强制审批且不可记住，但点错时它仍会执行。
- 安全等级只能由用户在设置页手动切换，外部应用无法通过 intent 修改。
- **使用本软件造成的任何数据丢失、设备损坏或账号风险，由使用者自行承担。**

## 已知限制

诚实列出，避免误导：

- **只跑通了一台设备**，别的手表既没测过也不保证
- 快速旋转表冠滑到列表顶部时，正文渲染有可感知延迟（原因未定位）
- 初始引导页尚未跟上当前手势体系
- 麦克风"取消即释放"只有单元测试与间接真机证据，缺少音频层的直接观测
- 设置页为一次性重写，个别子页仍需进入一次才刷新缓存值
