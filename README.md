# Wear Agent

圆形表盘上的端侧 AI Agent。它不是聊天机器人套壳：模型可以运行 shell 命令、给自己定义新工具，
并在专家模式下派生受限的子代理。所有特权操作都经过用户逐次审批。

## 功能

- **Agent 循环**：自主规划、调工具、看结果、继续；工具轮数不设上限（有能量提示与空转检测兜底）。
- **特权执行**：`run_shell` 按 ROOT / Shizuku / 本进程 三档自动选择后端；不可用时自动降级。
- **自写工具**：`define_tool` / `list_tools` / `remove_tool`，定义即持久化，下一轮出现在工具清单里。
- **子代理**：`run_subagent` 只在**专家安全模式**且开关打开时出现在工具清单，独立上下文、不可再派生。
- **审批门控**：14 条破坏性命令规则加 rm 目标分类；破坏性操作强制审批且不可记住。
- **局域网控制台**：手表内嵌 HTTP 服务，手机浏览器可改全部设置，四位数验证码加失败限流。
- **思考胶囊**：推理过程以 30dp 细标签折叠显示，展开后流式滚动，结束显示真实耗时。

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Wear OS 3+（API 33 及以上），圆形表盘 |
| 特权（可选） | Magisk root，或安装并激活 Shizuku；都没有时以普通应用身份执行 |
| 模型 | 任意 OpenAI 兼容端点（DeepSeek / 硅基流动 / 自建）+ API Key |

## 构建与安装

```bash
./gradlew :wear:assembleRelease
adb install -r wear/build/outputs/apk/release/wear-release.apk
```

首次启动在手表设置里填「接口地址 / API Key / 模型名」，或打开网页控制台在手机上填。

## 手势

| 操作 | 作用 |
|---|---|
| 底栏主键按住约 340ms | 说话（语音入口之一） |
| 底栏主键上滑 | 打开设置 |
| 底栏主键横滑 | 展开两翼副键 |
| 底栏主键单击 | 打开文字输入 |
| 设置页右滑或 BACK | 返回上一级，根页才退出设置 |
| 表冠旋转 | 滚动列表（对话页、设置页与所有子页） |
| 审批页点击 | 拒绝 |
| 审批页左滑 | 放行（滑不够会回弹） |

## 网页控制台

设置 → 网页控制台，页面显示形如 `http://192.168.1.x:8080/?t=1234` 的地址（含四位数验证码）。
手机连同一 Wi-Fi 打开即可。验证码连错 5 次锁定 60 秒；响应中的密钥一律掩码。

## 安全边界（务必阅读）

- 本应用可以执行任意 shell 命令。审批页是尊重用户的机制，不是安全沙箱。
- 破坏性命令（`dd of=/dev/block`、`mkfs`、`fastboot`、`pm uninstall com.android*` 等 14 类）
  每次都强制审批且不可记住，但仍可能在你点错时执行。
- 安全等级只有用户能在设置页手动切换，外部应用无法通过 intent 修改。
- 密钥保存在本机 SharedPreferences，已关闭云备份；网页响应中的密钥做掩码。
- 使用本软件造成的任何数据丢失、设备损坏或账号风险，由使用者自行承担。
